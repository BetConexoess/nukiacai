# AGENTS.md — nuKIaçaí


## Projeto

nuKIaçaí é uma landing page/cardápio interativo em HTML, CSS e JavaScript puro, mobile-first, com identidade roxa/violeta, pedido via WhatsApp e personagens quebrando a 4ª parede.

## Stack obrigatória

- HTML puro
- CSS puro
- JavaScript puro
- Sem React
- Sem Tailwind
- Sem Bootstrap
- Sem backend
- Sem bibliotecas externas na V1

## Regras de edição

Antes de editar:
1. explique o plano;
2. liste arquivos que pretende alterar;
3. aguarde aprovação.

Nunca:
- alterar preços sem aprovação;
- alterar número do WhatsApp sem aprovação;
- refatorar tudo;
- instalar dependência sem aprovação;
- copiar site externo exatamente.

## Recriação de design por referência

Quando receber uma URL ou screenshot:
1. analisar estrutura visual;
2. identificar hierarquia;
3. identificar padrões de layout;
4. identificar cores, espaçamentos e animações;
5. recriar com identidade própria do nuKIaçaí;
6. não copiar código, textos, imagens ou marcas protegidas.
