# SKILL — UX Copy e Quebra da 4ª Parede Nu Ki Açaí

## Nome da Skill

`SKILL_UX_COPY_QUARTA_PAREDE_NUKIACAI.md`

## Objetivo

Esta skill orienta agentes de IA, designers e desenvolvedores a escreverem todos os textos de interface, microcopy, CTAs, mensagens, estados e interações verbais da landing page **Nu Ki Açaí**.

A comunicação deve ser:

* Clara.
* Curta.
* Comercial.
* Divertida.
* Premium.
* Brasileira.
* Fácil de entender.
* Focada em pedido.
* Com quebra da 4ª parede em pontos estratégicos.

A regra principal:

**A Nu Ki Açaí deve parecer uma marca viva, que percebe a presença do visitante, conversa com ele e guia a escolha sem atrapalhar a compra.**

A quebra da 4ª parede é obrigatória, mas deve ser usada com inteligência. Ela deve melhorar a experiência, não virar piada em excesso.

---

# 1. Princípio Supremo

A ordem de prioridade da UX copy é:

```txt
1. Clareza
2. Conversão
3. Personalidade
4. Humor
5. Quebra da 4ª parede
```

Nunca sacrificar clareza para parecer engraçado.

Nunca esconder uma ação importante atrás de uma frase bonita.

Nunca usar piada em erro, pagamento, endereço, prazo ou problema de pedido.

A quebra da 4ª parede deve funcionar como tempero da marca, não como obstáculo.

---

# 2. Definição da Voz da Marca

A voz da Nu Ki Açaí é:

```txt
Premium, roxa, próxima, divertida, levemente provocativa, direta e desejável.
```

A marca fala como alguém que entende de açaí e sabe que o visitante está ali porque quer algo gostoso.

## A Nu Ki Açaí pode soar como:

* “Eu sei que você veio olhar o cardápio.”
* “Esse açaí está tentando chamar sua atenção.”
* “A gente facilita sua escolha.”
* “Pode pedir sem enrolação.”
* “Esse combo não apareceu por acaso.”

## A Nu Ki Açaí não pode soar como:

* Infantil demais.
* Debochada.
* Forçada.
* Desesperada para vender.
* Genérica de delivery.
* Fria como sistema bancário.
* Confusa como piada interna.

## Tom principal

Usar linguagem brasileira natural, simples e curta.

Preferir:

```txt
Você
Seu
Sua
Agora
Escolha
Monte
Peça
Ver
Adicionar
Confirmar

```

Evitar:

```txt
Usuário
Consumidor
Cliente final
Adquirir
Prosseguir
Submeter
Realizar solicitação
Clique aqui
Saiba mais
Começar
```

## Nível de humor

O humor deve ser:

```txt
Leve, contextual e rápido de entender.
```

Não usar piadas longas.

Não usar sarcasmo pesado.

Não usar humor que culpe o visitante.

Não usar frases que pareçam vigilância invasiva.

## Exemplo correto

```txt
Esse combo está tentando chamar sua atenção.
```

## Exemplo errado

```txt
A gente viu você parado aí faz tempo.
```

O primeiro parece divertido.
O segundo parece estranho e invasivo.

# 4. Definição da Quebra da 4ª Parede

Neste projeto, quebrar a 4ª parede significa:

```txt
A interface reconhece o visitante, a escolha, o clique, a rolagem ou o momento da navegação.
```

A página pode agir como se soubesse que existe alguém olhando para ela.

## Exemplos bons

```txt
Você chegou. O açaí percebeu.
```

```txt
Esse card apareceu com segundas intenções.
```

```txt
O botão está ali por um motivo.
```

```txt
Seu clique acabou de virar vontade.
```

```txt
Esse tamanho não é exagero. É planejamento.
```

## Exemplos ruins

```txt
Estamos te observando.
```

```txt
Você demorou demais para escolher.
```

```txt
Clica logo.
```

```txt
Se não pedir agora vai se arrepender.
```

A quebra da 4ª parede deve gerar cumplicidade, não pressão.

# 6. Onde NÃO Usar Quebra da 4ª Parede

Não usar em momentos críticos:

```txt
Erro de formulário
Pagamento
Falha de pedido
Endereço
CEP
Prazo de entrega
Reembolso
Cancelamento
Dados pessoais
Consentimento
Termos
Política de privacidade
Alerta importante
Problema com WhatsApp
Pedido atrasado
Produto indisponível importante
```

Nesses momentos, a copy deve ser clara, objetiva e respeitosa.

## Errado

```txt
Ops, o açaí tropeçou no pagamento 😅
```

## Certo

```txt
Não foi possível confirmar o pagamento. Tente novamente ou fale com a loja pelo WhatsApp.
```

# 7. Regras de Clareza

Toda frase deve responder pelo menos uma dessas perguntas:

```txt
O que é isso?
O que acontece se eu clicar?
O que eu preciso fazer?
Qual é o próximo passo?
Por que estou vendo isso?
Como resolvo esse problema?
```

Se a frase não responde nada e só tenta ser engraçada, remover.

## Regra prática

Antes de aprovar qualquer texto, perguntar:

```txt
Uma pessoa com pressa entenderia isso em 2 segundos?
```

Se não entender, reescrever.

# 8. Regras de CTAs

CTA é texto de ação. Ele precisa ser específico.

## Fórmula ideal

```txt
Verbo + objeto + contexto opcional
```

## Bons CTAs

```txt

Ver cardápio
Escolher tamanho
Adicionar ao pedido
Ver combos
Pedir pelo WhatsApp
Montar pedido no WhatsApp
Escolher adicionais

```

## CTAs com personalidade

```txt
Montar meu açaí
Escolher meu exagero
Ver os favoritos
Pedir esse agora

Fechar meu pedido
```

## Evitar

```txt
Clique aqui
Saiba mais
Começar
Enviar
Ok
Prosseguir
Avançar
Continuar
```

Só usar “Continuar” se o contexto estiver extremamente claro.

# 16. Empty States

Empty state é quando algo está vazio.

A copy precisa explicar e dar saída.

## Fórmula

```txt
O que aconteceu + como resolver
```

## Busca sem resultado

```txt
Nada apareceu com esses filtros.
```

Complemento:

```txt
Limpe os filtros ou escolha outra categoria.
```

Versão com 4ª parede:

```txt
A gente exagerou nos filtros e zerou a vitrine.
```

Complemento:

```txt
Limpar filtros?
```

## Carrinho vazio

```txt
Seu pedido ainda está vazio.
```

Complemento:

```txt
Escolha um açaí para começar.
```

Versão com 4ª parede:

```txt
Seu pedido ainda não existe, mas ele já tem potencial.
```

Complemento:

```txt
Escolha o primeiro item.
```

## Sem adicionais selecionados

```txt
Nenhum adicional escolhido ainda.
```

Complemento:

```txt
Escolha seus favoritos para completar o pedido.
```

Versão com 4ª parede:

```txt
O açaí está esperando os parceiros dele.
```

# 19. Mensagens de Erro

Erro não é lugar de piada.

## Fórmula

```txt
O que aconteceu + como corrigir
```

## Regras

```txt
Não culpar o usuário.
Não usar emoji.
Não usar piada.
Não usar “ops deu ruim”.
Não esconder o problema.
Não usar termos técnicos.
Manter a solução visível.
```

## Exemplos

### WhatsApp inválido

```txt
Digite um WhatsApp válido.
```

### CEP inválido

```txt
Informe um CEP válido para calcular a entrega.
```

### Falha ao carregar cardápio

```txt
Não foi possível carregar o cardápio. Recarregue a página ou fale com a loja pelo WhatsApp.
```

### Produto indisponível

```txt
Este produto não está disponível agora.
```

Complemento:

```txt
Escolha outra opção ou fale com a loja pelo WhatsApp.
```

### Pedido não enviado

```txt
Não foi possível enviar o pedido. Verifique sua conexão e tente novamente.
```

### WhatsApp não abriu

```txt
Não foi possível abrir o WhatsApp automaticamente.
```

Complemento:

```txt
Copie a mensagem do pedido e envie para a loja.
```

# 20. Tooltips e Textos de Ajuda

Tooltip deve ajudar, não esconder informação importante.

## Regras

```txt
Tooltip é apoio, não instrução obrigatória.
Deve ser curto.
Deve funcionar também com foco de teclado.
Não deve conter link importante.
Não deve conter preço essencial escondido.
```

## Exemplos

```txt
Adicional grátis dentro do limite escolhido.
```

```txt
Pode alterar o valor final.
```

```txt
Combina bem com frutas e granola.
```

```txt
Disponibilidade pode variar no dia.
```

Versão com personalidade leve:

```txt
Esse topping costuma se dar bem com banana.
```

# 28. Regras de Acessibilidade na Copy

A copy precisa funcionar para todos.

## Regras

```txt
O texto visível do botão deve explicar a ação.
O aria-label não deve contradizer o texto visível.
Não usar apenas emoji para comunicar algo.
Não colocar informação importante só no hover.
Não usar texto importante dentro de imagem.
Evitar frases longas.
Evitar trocadilhos difíceis.
Mensagens de erro devem ficar perto do campo.
Estados de loading e sucesso devem ser anunciáveis no HTML.
```

## Exemplo ruim

```html
<button aria-label="Enviar pedido para o WhatsApp">Bora</button>
```

## Exemplo melhor

```html
<button aria-label="Montar pedido no WhatsApp">Montar pedido no WhatsApp</button>
```

# 29. Regras para Emojis

Emojis são opcionais e devem ser raros.

## Pode usar

```txt
Confirmação leve
Promoção
Mensagem social
WhatsApp
```

## Não usar

```txt
Erro
Pagamento
Aviso importante
Acessibilidade
Dados pessoais
Prazo de entrega
Política de privacidade
```

## Regra

```txt
No máximo 1 emoji por bloco.
Emoji nunca substitui palavra.
```

Bom:

```txt
Pedido enviado para o WhatsApp 💜
```

Ruim:

```txt
💜🍓😋🔥 Peça agora!!! 🔥😋🍓💜
```

A página deve contar uma história.

```txt

3. O Hero apresenta a promessa.
```

# 32. Regras de Revisão

Antes de aprovar qualquer texto, verificar:

```txt
Está claro?
É curto?
Diz a ação real?
Ajuda a vender?
Parece Nu Ki Açaí?
Tem personalidade?
A 4ª parede está natural?
Não parece invasivo?
Não usa humor em momento crítico?
Funciona no mobile?
Funciona para leitor de tela?
Não depende só de hover?
```

Se falhar em clareza, reescrever.

Se falhar em conversão, simplificar.

Se falhar em personalidade, adicionar uma frase leve.

Se falhar em acessibilidade, corrigir antes de publicar.

# 33. Checklist Final da Skill

A UX copy da Nu Ki Açaí deve sempre:

```txt
Ser clara antes de ser criativa.
Usar tom brasileiro e direto.
Falar com “você”.
Ter CTAs específicos.
Evitar “clique aqui” e “saiba mais”.
Usar 4ª parede em momentos leves.
Evitar 4ª parede em erros e pagamentos.
Transformar o cardápio em experiência.
Guiar o pedido até o WhatsApp.
Usar humor sem atrapalhar.
Ser acessível.
Ser consistente.
Vender sem pressionar.
Parecer viva sem parecer invasiva.
```

# 34. Resumo Operacional

Quando um agente escrever copy para o Nu Ki Açaí, ele deve seguir esta lógica:

```txt
1. Entender o componente.
2. Definir a ação principal.
3. Escrever a versão mais clara.
4. Encurtar.
5. Adicionar personalidade se couber.
6. Adicionar 4ª parede somente se melhorar a experiência.
7. Remover humor em momentos críticos.
8. Garantir acessibilidade.
9. Garantir consistência com a marca.
10. Revisar se o texto ajuda o pedido.
```

A Nu Ki Açaí não fala como um sistema comum.

Ela fala como uma marca roxa, viva e premium que sabe que o visitante chegou para escolher algo gostoso.

A frase guia da skill é:

```txt
A página percebe o visitante, mas nunca atrapalha o pedido.
```
